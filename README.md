# Java Coding Challenges

This repository contains Java solutions to a variety of coding problems that I solved while learning core programming concepts, logic building, and problem-solving techniques. It is a record of my practice and improvement over time, covering beginner-friendly exercises as well as foundational algorithmic thinking.

## About this repository

The goal of this project is to strengthen understanding of:

- Java syntax and fundamentals
- Conditional statements and loops
- Mathematical logic and pattern-based problems
- Basic algorithms and number theory
- Problem-solving mindset through repeated practice

Each program is a small challenge designed to improve confidence and build a strong foundation in programming.

## Topics covered

This repository includes solutions for problems such as:

- Basic arithmetic and number operations
- Prime, palindrome, and Armstrong checks
- Factorials, Fibonacci series, and natural number sums
- Largest/smallest value comparisons
- Even/odd, positive/negative, and leap year logic
- Voting eligibility, grading, and basic decision-based programs
- String and number-based challenge implementations

## Example challenges included

- Absolute Value
- Armstrong Number
- Even or Odd
- Factorial of a number
- Fibonacci Series
- Largest number from given 2 numbers
- Largest number from given 3 numbers
- Prime number or not?
- Reverse the integer
- Pythagorean Tripet
- Sum of N natural numbers
- Voting Eligibility
- Word representation for a number
- Week days
- Leap year

## Why this repository exists

This is more than just a collection of Java programs. It represents continuous learning, experimentation, and growth in programming. Each file reflects a challenge solved during the journey of learning algorithms and data structures.

## How to use

You can open any Java file and run it with the Java compiler:

```bash
javac FileName.java
java FileName
```
